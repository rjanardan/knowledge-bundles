# Bundle conventions

Frozen on 2026-09-11 after two batches, because these rules are cheap to change now and expensive after sixty files. Changing one requires an entry in `/log.md` saying what changed and why. This file carries no claims about the world, so it is the only concept in the bundle whose footnotes point at the specification rather than at a fact.

## Layout

| Path | Holds | Type |
| --- | --- | --- |
| `companies/` | Frontier labs, platforms and vendors | `Company` |
| `founders/` | People named as founders, and founders' track records | `Person` |
| `investors/` | Venture, growth and corporate funds | `Investor` |
| `ai-domains/` | Technical fields a company operates in | `Domain` |
| `ai-use-cases/` | What the technology is sold to do | `UseCase` |
| `technologies/` | Frameworks, serving stacks and contributed standards | `Technology` |
| `models/` | Named model releases and model families | `Model` |
| `institutions/` | Universities and labs founders came out of | `Institution` |
| `people/` | Non-founder executives, for engineering-leadership questions | `Person` |
| `images/` | Media cited by concepts | non-concept |
| `_tools/` | Linter and index generator | non-concept |

One entity or idea per file. File names are lowercase-hyphenated. `index.md` and `log.md` are reserved by the specification, in the bundle root and in subdirectories; subdirectory indexes carry no frontmatter and are generated by `_tools/build-index.py`, so editing one by hand loses the edit.

## Frontmatter keys

Required on every concept: `type`, `title`, `description`, `resource`, `tags`, `aliases`, `status`, `generated`, `stale_after`, and `sources`. Optional: `relations`, `founded`, `hq`, `image`.

* `aliases` is mandatory, not decorative: it is the dedupe key when the same entity is reached by two names, which is the common failure in a graph built from press coverage.
* `status` is `draft` until a batch is signed off, then `stable`.
* `generated.by` uses the runtime model label, so a reader can tell which model produced a file.
* `verified` is deliberately absent. Under OKF §5.3 it means machine-confirmed or human-reviewed, and it is added only when a batch is signed off - never by the generator.

## Edges

Edges are typed, live in the `relations` frontmatter block as `{ type, target, ... }`, and use bundle-absolute paths per §6.1. Extra keys are free-form and carry the qualifier: `since`, `from`, `to`, `role`, `round`, `amount_usd`, `at`, `note`, `alias`.

| Type | Direction | Mirror |
| --- | --- | --- |
| `founded-by` | company/person to person | none |
| `founded` | person to company | none |
| `co-founded-with` | person to person | none |
| `created` | person to artefact | none |
| `employs` | person to company, or company to person | none |
| `previously-at` | person to company | none |
| `educated-at` | person to institution | none |
| `invested-by` | investee to investor | `invested-in` |
| `invested-in` | investor to investee | `invested-by` |
| `owns` | parent to subsidiary | `subsidiary-of` |
| `subsidiary-of` | subsidiary to parent | `owns` |
| `operates-in` | company to domain | none |
| `applies-to` | company to use case | none |
| `contributes-to` | actor to standard or artefact | none |
| `ships` | company to model family | `developed-by` |
| `developed-by` | model to company | `ships` |
| `uses` | actor to technology | none |
| `customer-of` | customer to supplier | none |
| `partners-with` | actor to actor | none |
| `competes-with` | actor to actor | none |
| `related-to` | concept to concept | none |

**One fact, one edge.** A relationship is recorded on the file that owns the evidence. Mirrors exist only where the pair reads naturally from both sides - `invested-by` and `invested-in`, `ships` and `developed-by`, `owns` and `subsidiary-of` - and a consumer counting a relationship must treat a mirror pair as one edge. `customer-of` is not mirrored: the supplier's file does not repeat it.

**Pending targets are legal.** A `relations` target that has no file yet is knowledge not yet written, per §6.1, not a broken link. `_tools/okf-check.py` reports them as information so that the next increment can be chosen from inbound degree rather than from taste.

## Attribution

Every load-bearing sentence carries a footnote written as `[^<id>]`, and the id is the `id` of a `sources` entry in the same file. Two mechanical rules keep this auditable, and both are enforced by the linter:

1. Every inline footnote reference needs a matching definition line, in the form `[^<id>]: Author, "Title", URL`, at the foot of the file, and every definition needs to be referenced.
2. Every `sources[].id` needs to be cited somewhere, or it is dead weight and should be removed.

The author namespace carries the signal that a credibility score would otherwise carry: `human:<slug>` for a person, `org:<slug>` for a company, press outlet or analyst tracker, `wiki:<lang>` for a community-edited reference work, `team:<slug>` for a named internal group. No credibility field is stored, because §5.1 requires credibility to be inferred rather than persisted. A source that was only read as a headline says so in its `title`.

## Staleness

| Fact type | Window | Rationale |
| --- | --- | --- |
| Company funding, valuation, run-rate | 90 days | Rounds and revenue are the fastest-moving facts here |
| Model releases and current model line | 90 days | Three labs now ship point releases inside a quarter |
| Contributed standards and protocols | 90 days | Revisions are dated and breaking |
| Domain concepts, papers, benchmarks | 365 days | The literature moves more slowly than the product surface |
| Founder affiliations, education, track record | 365 days | Employment changes are slower than valuations |

## Images

Only assets with an explicit licence are bundled, and the credit is copied exactly as the source states it - never guessed, never reconstructed. Each asset is copied into `images/` rather than hotlinked, its bytes are hashed, and the concept that uses it records `licence`, `licence_url`, `file`, `sha256` and `retrieved` in the `sources` entry for the asset, with a caption footnote in the body. Crops are derivatives and are labelled as such in the caption, because CC BY requires it. Display size is normalised so that a 32-pixel mark and a wordmark do not render at wildly different weights, and every SVG is scanned for embedded script before it is committed.

## Never written

* **Secrets.** No API keys, tokens, passwords or connection strings, in any field, ever.
* **Rumour as an edge.** A disputed or single-source claim goes in the file's last section, labelled, and never becomes a `relations` entry.
* **Inferred architecture.** Where no source states parameter counts, mixture-of-experts use, pretraining data or training compute, the field is left empty and the file says so. An empty field with a stated reason is a better artefact than a plausible number.

## Scope merges recorded

Google and Alphabet share one concept (`/companies/google.md`), because the pending-target list referenced `google` and no separate `alphabet` node existed; the file states the merge at its head. Corporate money is modelled as a company-to-company edge rather than as an `investors/` concept, so a strategic investor such as Amazon or Nvidia appears as a company node with an investment edge.
